# Ducky Bird

A swimming duck game inspired by Flappy Bird.

## Controls

- Press Space to start.
- Hold Space to dive; release it to float up.
- Collect bread to score and push the crocodile back.
- Fish change the duck's colour and give a speed boost.
- Avoid seaweed, trash and the crocodile.
- Press R after game over to restart.

Open index.html to play. The supplied sketch is preserved unchanged. Sound is disabled in the supplied code (`USE_SOUND = false`), so the game runs without additional audio files. See ASSETS.md before enabling sound.
