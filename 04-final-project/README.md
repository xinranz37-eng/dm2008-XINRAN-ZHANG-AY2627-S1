# My Pudding Squishie

An interactive pudding toy made with p5.js.

Click or tap, hold to squeeze, and drag to stretch the pudding. Use the Sound button to enable audio and Reset to start again. Repeated squishes produce mini puddings; 100 total squishes trigger an explosion and a restart screen.

Run index.html with a local web server. The original project code and sound files are preserved. The page loads its p5 libraries from a CDN, so an internet connection is required.
