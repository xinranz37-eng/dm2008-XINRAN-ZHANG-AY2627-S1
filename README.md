## Running the sketches

Open the root `index.html` to browse the activities and projects. For Sensor Jam and audio projects, serve the repository locally:

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000 in a browser. Sensor Jam uses Web Serial and requires a compatible browser such as Chrome. My Pudding Squishie loads its libraries from a CDN and needs an internet connection. Ducky Bird currently has sound disabled; its optional audio requirements are listed in its project folder.

## Documentation

Activity documentation folders contain JPEG images and MP4 demonstrations. Arduino photos and videos are preserved in `arduino/documentation` with their original filenames. Screen recordings show the current sketches running.
