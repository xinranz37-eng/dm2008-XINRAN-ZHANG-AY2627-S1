# activity_9a · Mapping Sensors

Use the course analog-output distance sensor on A0. PWM pin 9 → 220–330 Ω resistor → LED anode; cathode → GND. Distance 5–100 cm maps to brightness 255–0, with smoothing. Verify the sensor model before upload. Needed: 2–3 real setup photos and a demo video.

Open each sketch in its identically named folder in Arduino IDE. Code prepared with AI assistance; not compiled with an Arduino board core or tested on hardware in this session. Do not mark the physical activity complete until wired and observed.
